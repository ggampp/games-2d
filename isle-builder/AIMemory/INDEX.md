# AIMemory — Índice

Este diretório é a memória compartilhada para agentes de código neste projeto
(protocolo **Colmeia Handoff**). Leia estes arquivos no início de cada sessão,
nesta ordem:

1. `PROJECT_OVERVIEW.md` — o que é o projeto e suas regras rígidas.
2. O final de `work.log` — os eventos mais recentes.
3. Os arquivos mais novos em `handoffs/` — onde o último agente parou.

## Conteúdo

- `PROJECT_OVERVIEW.md` — fatos duráveis, convenções e armadilhas do projeto.
- `work.log` — fluxo de eventos somente append (nunca edite entradas passadas).
- `handoffs/` — handoffs estruturados entre agentes/sessões.
- `knowledge/` — decisões duráveis e lições promovidas.
- `archive/` — logs rotacionados/frios e handoffs substituídos.

Veja `docs/PROTOCOL.md` no repositório colmeia-handoff para o contrato completo.
