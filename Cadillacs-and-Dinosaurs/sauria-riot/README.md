# Sauria Riot

Beat 'em up original no navegador (Phaser 3). Não usa assets nem nomes de Cadillacs and Dinosaurs.

Yucca Prime, 2194. Quatro caçadores contra a Helix Dominion e saurianos de laboratório. Um estágio completo até o chefe Ashjaw.

## Rodar

```bash
cd sauria-riot
npm install
npm run dev
```

Abre `http://127.0.0.1:3000`.

## Controles

| Ação | Teclado | Gamepad |
|---|---|---|
| Mover / profundidade | WASD ou setas | analógico / D-pad |
| Soco / combo | Z ou J | botão A / X |
| Pulo / chute aéreo | X, K ou Espaço | B / Y |
| Especial | C, L ou Shift | RB / Y |
| Confirmar | Enter | |

Especiais: Rook marreta, Vesper dash-corte, Toro arremesso, Quinn tiro (munição limitada).

Toque virtual aparece em tela grossa / mobile.
