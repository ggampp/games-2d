# games-2d

Exemplos de jogos **2D / HD-2D** no browser. Gameplay em plano 2D, mesmo quando o render é Three.js ortográfico.

Cada pasta é um projeto independente. Instale e rode **dentro** dela.

| Pasta | Loop | Stack | Como rodar |
|---|---|---|---|
| [`td-cats-dogs/`](./td-cats-dogs) | Tower defense | Phaser 3 | `npm install && npm run dev` |
| [`LongSpectrum/`](./LongSpectrum) | Puzzle de ótica | Canvas 2D | servir a pasta |
| [`glint/`](./glint) | Action RPG HD-2D | Three.js | `npm install && npm run dev` |
| [`ironclad-rampage/`](./ironclad-rampage) | Beat 'em up 2.5D | Three.js | `npm install && npm run dev` |
| [`isle-builder/`](./isle-builder) | Sandbox top-down | Three.js ortográfico | `npm install && npm run dev` |
| [`favor-dos-deuses/`](./favor-dos-deuses) | Action RPG top-down | Phaser 3 | `npm install && npm run dev` |
